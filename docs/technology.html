On-device chat

Neuravale's own JavaScript CPU inference engine runs in a browser worker. No WebGPU or external AI API is required. Your messages are processed locally in memory and are not sent to a model server. Static files are fetched from GitHub Pages or GitHub's raw file host. Model weights are publicly downloadable, not confidential.

Performance and browser support vary by device. No account, persistent chat storage, file understanding or hosted API is provided. Optional reference lookup sends only the entered search query to Wikipedia. The calculator, unit converter and text statistics use deterministic code, not model inference.
