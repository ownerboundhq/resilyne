Build with Neuravale.

Install Python 3.11+ and Ollama. Clone the repository and run the local API.

Local setup

git clone https://github.com/ownerboundhq/resilyne.git
cd resilyne
ollama pull qwen2.5:3b
python -m venv .venv
# Activate your virtual environment
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000/docs for interactive API documentation.

API examples

curl http://127.0.0.1:8000/api/models
curl -N -H "Content-Type: application/json" \
  -d '{"message":"Hello","model":"qwen2.5:3b"}' \
  http://127.0.0.1:8000/api/chat

No public API endpoint, authentication or production rate limits are available. Do not expose this local service directly to the internet.
