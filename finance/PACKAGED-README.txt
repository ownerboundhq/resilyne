NEURAVALE FINANCE DESKTOP 0.8.0 - Windows x64 preview

1. Extract ALL files from the ZIP to a folder.
2. Double-click NeuravaleFinance.exe. Keep the other folders beside it.
3. Click Start team and watch accounting workflow.
4. Watch Chromium navigate the fictional ledger, download records, post a permitted CAD 3 bank fee, and verify the result.
5. Click Open activity dashboard to see the remaining discrepancy and report.
6. Open local workspace/operations to inspect screenshots and source evidence.
7. Optional: enable scheduled read-only browser exports before starting the worker.

Python, Git and a separate browser installation are not required.
An optional Excel report requires desktop Microsoft Excel and permission to run its PowerShell script.
The app is unsigned; Windows may warn you. Verify the published SHA-256 before running.
No automatic startup task is installed by this portable package. Closing the launcher stops its worker.
Keep the computer awake. The package does not modify your existing AI training software.
Data and logs: %USERPROFILE%\Neuravale-finance-desktop-demo-v06
Uninstall by stopping the worker, closing the launcher and deleting the extracted app folder.
Local workspace data remains unless you explicitly delete it.

This is a fictional-data pilot, not a licensed accounting service.
No live QuickBooks/Wave/Sage/Shopify connections, payments, payroll, tax filing, general AI
computer use or Neuravale model inference are enabled. Do not enter real financial data.
No third-party AI API is required. The browser fixture is local.

MONTH END: Click Prepare full specialist month-end close. Open dashboard, review the checks and statements. Click Review and seal month-end snapshot only after review. This only seals a local fictional snapshot; no live books are closed.

The full specialist demo calculates FIFO COGS, reconciles payroll and GST/HST, and produces four balanced local adjusting entries (COGS, accrual, prepaid amortization, depreciation). It does not compute statutory payroll deductions, determine actual GST/HST eligibility, file tax returns, or post to external applications.

INTEGRATIONS: click Connect your software (test integrations). Four session-only API sample readers are implemented; test credentials required. Other catalog items remain planned. No automatic posting or ongoing API sync.

PHYSICAL COMPUTER USE: click Watch physical mouse and keyboard accounting. Start and approve inside the practice window. Watch the real mouse enter the four calculated journals. Escape, moving the mouse or switching windows stops. Keep the window fully visible on the primary monitor. Restricted fictional fixture only; no arbitrary application control. Physical interactive behavior must be tested on your laptop.
