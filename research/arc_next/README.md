# Arc Next — original language-model research

Arc's previous 170,725-parameter word-level model is preserved. This is a new architecture initialized from random weights, not a continuation of the incompatible old checkpoint. The default configuration is 4 decoder layers, width 256, 4 heads, 128-token context, a 4,096-piece SentencePiece BPE tokenizer with byte fallback, and tied embedding/output weights (about 4.24 million parameters). No external pretrained weights are loaded.

## Data

- HuggingFaceTB/cosmopedia: Apache-2.0, synthetic educational prose generated by Mixtral; three bounded source subsets. https://huggingface.co/datasets/HuggingFaceTB/cosmopedia
- OpenAssistant/oasst1: Apache-2.0, human conversations; English, filtered by review/rank/labels, separate official validation split. https://huggingface.co/datasets/OpenAssistant/oasst1
- The prepare script records the resolved dataset revision, dataset file hashes and counts. Training text is not committed to the public repository. The corpus requires further quality, rights and safety review before commercial use; automatic PII and quality filtering is incomplete. Attribution does not guarantee every example is safe or accurate.

## Run on your own compute

Install PyTorch (CPU or CUDA), datasets==3.6.0, sentencepiece==0.2.1, and huggingface_hub==0.32.4.

```sh
python research/arc_next/prepare.py --docs 10000
python research/arc_next/train.py --pre-steps 1500 --chat-steps 500 --seconds 660
```

For GPU experiments increase token budget on your own compute. To resume, reuse the original data, tokenizer and output directory and pass --resume research/arc_next/run/checkpoint.pt. Resume adds new steps in both stages; set --pre-steps 0 or --chat-steps 0 to skip a stage's updates.

The one-off GitHub workflow runs a bounded research smoke experiment and preserves a model checkpoint, tokenizer, measured held-out loss and raw generated sample responses as run artifacts. It never replaces the public model. Lower perplexity is not evidence of correct answers; independent factual, arithmetic, dialogue, privacy and safety evaluation and browser-runtime implementation are required before promoting any successor. The default Arc remains unchanged.
