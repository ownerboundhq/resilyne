04 / QUESTIONS

Good to know.

Is Resilyne a coding assistant?+

No. The goal is ongoing software maintenance: detect failures, investigate their cause and prepare fixes without waiting for you to write a prompt. You can continue using your preferred editor or coding agent.

Will it change production code on its own?+

The current engine prepares eligible single-file fixes and can optionally open draft pull requests. Merging requires explicit authorization and configured CI verification. It does not independently deploy production changes.

What applications are supported?+

The current development scope is personal GitHub repositories, eligible JavaScript and TypeScript source files, and a selected GitHub Actions workflow. Runtime health monitoring and dependency alerts are available in the backend implementation. Other stacks and native cloud integrations are not yet supported.

Can I sign up today?+

The local scanner and MCP server are available in the repository. Hosted accounts are not open yet because the backend is not deployed. See Connect for installation instructions.
